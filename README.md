Scrapping-python-project
This repository demonstrates my python web scrapping skills

What does it do?
Extracts product names, categories, prices, ratings, and availability.
Lets you choose how many pages to scrape.
Saves the extracted information into both CSV and JSON files.


How to use it

Make sure you have Python, Google Chrome, and Selenium installed.

install python from python.org
install an IDE (Code editor)

You can either install pycharm
or visual studio code 
(Pycharm is way easier to use)

2.Install Selenium with:

Run the script:

Once it's finished, you'll find two files containing the extracted data:

-extractedinfoproducts.csv

Why I made this

I built this project to practice web scraping with Selenium, working with multiple pages, and saving scraped data in different formats.

It's a small project, but it helped me get more comfortable with Python and browser automation.
